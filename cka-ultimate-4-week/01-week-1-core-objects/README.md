# Week 1 — Core Objects, Scheduling, Networking and Storage

Build the object model and command fluency that everything else depends on. Troubleshooting is introduced immediately rather than postponed.

## Rule for this week

Every lab starts with host/context verification and ends with explicit evidence. Do not mark a lab complete because a manifest applied without an error.
