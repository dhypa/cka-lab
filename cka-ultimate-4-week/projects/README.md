# Capstone Projects

The course contains three projects. Each is deliberately written as a fully dressed lab so it has setup, success criteria, verification, failure injection, cleanup and debrief rather than becoming a vague “build something” assignment.

1. **Week 1 — Stateful Web Tier** — [`Lab 15`](../01-week-1-core-objects/day-07/lab-15-week-1-capstone-ship-a-stateful-web-tier.md): combine configuration, probes, scheduling, storage, Service/DNS and troubleshooting.
2. **Week 2 — Recover and Maintain the Platform** — [`Lab 30`](../02-week-2-cluster-admin/day-14/lab-30-week-2-capstone-recover-and-maintain-the-platform.md): etcd evidence, RBAC, worker lifecycle, certificate inventory, Helm/Kustomize and safe incident response.
3. **Week 3 — Multi-Layer Outage** — [`Lab 45`](../03-week-3-networking-debug/day-21/lab-45-week-3-capstone-multi-layer-outage.md): an unknown four-fault incident spanning workloads, Services, policy, DNS and node/system layers.

Do not read their solution files before the first attempt. Repeat each capstone faster after remediation.
