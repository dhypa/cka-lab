# Week 3 — Networking, Extensibility and Incident Response

Modern networking APIs and extension mechanisms are paired with increasingly realistic outages. The goal is an evidence-driven troubleshooting reflex.

## Rule for this week

Every lab starts with host/context verification and ends with explicit evidence. Do not mark a lab complete because a manifest applied without an error.
