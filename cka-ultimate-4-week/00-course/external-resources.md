# External Resources

The repository is sufficient as a course spine. External material should fill a specific explanation/practice gap, not replace terminal time.

## Tier 1 — source of truth

- **Linux Foundation CKA certification page** — current blueprint, version, duration, simulator entitlement and policy links.  
  https://training.linuxfoundation.org/certification/certified-kubernetes-administrator-cka/
- **Linux Foundation CKA/CKAD Important Instructions** — exam host workflow and task-host tooling.  
  https://docs.linuxfoundation.org/tc-docs/certification/important-instructions-cka-ckad
- **Kubernetes documentation** — technical source of truth.  
  https://kubernetes.io/docs/
- **kubectl quick reference** — speed and syntax retrieval.  
  https://kubernetes.io/docs/reference/kubectl/quick-reference/
- **Helm docs** — current Helm commands/concepts.  
  https://helm.sh/docs/
- **Gateway API docs** — current Gateway API resource/version guidance.  
  https://gateway-api.sigs.k8s.io/

## Tier 2 — structured explanation / extra labs

- **Linux Foundation LFS258, Kubernetes Fundamentals** — official training aligned to administrator fundamentals. Paid; optional.
- **Killer.sh CKA simulator** — currently bundled with CKA purchase according to the certification page. Use attempts as timed diagnostics, not as a question bank.
- **KodeKloud CKA course/labs** — strong optional source of additional hands-on repetitions. Check that the course advertises the current CKA curriculum/version before relying on it.
- **Techiescamp CKA guide** — useful community checklist/explanations; cross-check any exam claim against Linux Foundation/upstream docs.

## Resource rule

When community content conflicts with current official docs, follow current official docs. Kubernetes and the exam minor move quickly enough that a highly ranked older article can be technically correct for its date and still be wrong for your exam.
